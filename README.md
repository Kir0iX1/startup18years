# СТАРТ18 — Архитектура твоего дохода

Исследовательская платформа о том, как начать зарабатывать с 18 лет: актуальные профессии 2026 года, дорожная карта роста дохода, интерактивный калькулятор потенциала и тест на подбор направления.

## Разделы

- **Исследование рынка** — 12 актуальных профессий с зарплатными вилками и фильтром по категориям
- **Дорожная карта 18 → доход** — стратегия роста дохода в 4 этапа
- **Калькулятор потенциала** — интерактивная модель дохода по направлению, времени и горизонту
- **Тест «Подбери своё направление»** — 4 вопроса, определяющих подходящую категорию профессий
- **Шесть принципов дохода** — ключевые выводы исследования
- **FAQ** — ответы на типичные страхи и ошибки новичков

## Технологии

- [Next.js](https://nextjs.org) (App Router)
- [Tailwind CSS](https://tailwindcss.com)
- TypeScript

## Запуск локально

```bash
pnpm install
pnpm dev
```

Открой [http://localhost:3000](http://localhost:3000) в браузере.
